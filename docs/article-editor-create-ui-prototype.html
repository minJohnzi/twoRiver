文章创建与编辑页面：先把写作本身放到画面中央。

为什么重做编辑页

当前页面承载了标题、摘要、正文、翻译、标签、封面、发布状态和格式转换。新的布局把这些信息重新分层：写作内容在画面中心，发布动作保持可达，但不抢走注意力。

中间的纸面不是装饰，它提供清晰的阅读宽度和写作节奏；左栏负责结构导航，右栏负责元信息与发布检查。

图片 / 表格 / 代码块预览位。等待用户提供真实内容时保持占位，不伪造数据。

信息密度怎么分层

一级信息是标题和正文。二级信息是摘要、语言和编辑工具。三级信息是标签、封面、Slug、检查清单。这样创建文章时不会像填报表，编辑文章时也能迅速定位发布风险。
